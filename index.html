《慢慢便利店》隐私政策

更新日期：2026 年 10 月 19 日

米多多的工作室是《慢慢便利店》的运营开发者。本政策说明 Android 游戏本身如何处理设备内的经营进度、您主动选择的备份文件，以及您通过邮件联系我们时提供的信息，适用于 0.5.0、0.4.0、0.3.0，以及此前 0.1.0、0.2.x 离线版本。普通离线版与可选广告版的信息处理分别说明。0.5.0 普通离线构建不包含广告 SDK 或联网权限；可选广告构建仅在下述条件下使用对应服务。

一、游戏本身的信息处理

本游戏为单人经营游戏，不提供玩家账号、联网聊天、云存档、真实货币购买或支付功能。普通离线构建没有广告、联网权限或第三方 SDK；0.3.0 起的可选安卓广告构建只为自愿观看激励广告增加联网及网络状态权限，经营进度仍保存在本设备。

游戏代码不要求您提供姓名、手机号码、身份证信息或其他身份资料，不读取您的相机、麦克风、位置、通讯录或整个存储空间，不向开发者服务器上传游戏进度。

可选广告服务（仅安卓广告构建）

SDK 名称：TapADN SDK 5.3.0.4（非聚合）；提供者：上海艾得蒽数字科技有限公司。仅当您主动请求广告并同意广告说明后初始化和加载，拒绝后仍可正常经营。SDK 用于广告展示、归因、统计与反作弊，可能处理 IP 地址、设备品牌型号、系统版本、屏幕与语言信息、应用包名版本、前后台状态、广告展示点击与验证信息及性能崩溃信息；保存期限与权利处理请查看 SDK 政策。

本版关闭个性化广告及可选的定位、电话状态、Android ID、OAID、应用安装列表、Wi-Fi 详情、MAC 和传感器采集，不申请对应权限，也不向广告平台上传经营存档或您选择的备份文件。SDK 仍处理上述必要信息，不能视为匿名或零收集。

广告奖励回执、当日领取状态及同意版本会保存在本设备，用于发放及防止重复领取。设置内可撤回广告同意并保存退出；重新打开后不初始化 SDK，除非您再次主动同意。游戏币不是现实货币，也不可提现。

二、本地进度与保存期限

为了在下次打开时继续经营，游戏会在本设备的应用存储中保存经营天数、游戏币余额、商品库存与售价、店铺升级、经营记录以及音效等设置。保存这些数据的目的，是恢复进度和保留您的操作偏好。 0.4.0 新增的虚构常客故事选择、好感、购买偏好、街坊订单及场景纪念物也仅保存在本设备，供恢复剧情和经营进度，不采集您的真实生活经历，也不向广告平台上传这些内容。

本地进度会保留到您在游戏内重置进度、清除应用数据或卸载应用时。重置或清除可能无法撤销，本版本不提供开发者服务器上的进度恢复。TapPlay 环境内的存档与直接安装 APK 的本地存档并不自动互通。

三、您主动进行的备份与恢复

当您主动选择备份或恢复时，Android 版通过系统文档选择器让您选择保存位置或单个 JSON 存档文件。游戏只处理您选择的文件，不申请访问整个存储空间的权限，也不会自动上传备份。

备份是保存经营进度与设置的 JSON 文件。您可以自行保管、复制或删除它。若您选择云盘或其他文件提供者作为保存位置，其同步与信息处理由您选择的服务及设置决定，请查看对应服务的隐私说明。删除游戏本地进度不会自动删除您另行保存的备份。

四、通过 TapPlay 游玩时的平台服务

通过 TapTap 的 TapPlay 环境游玩时，TapTap 平台会按其服务功能、您的选择与授权，以及适用规定处理平台账号、身份验证、实名认证、防沉迷限制和游戏时长等相关信息。这些平台服务由 TapTap 提供，与本游戏 APK 内的经营存档处理分别说明。

本游戏 APK 没有内置 TapTap 登录或合规认证 SDK，也不接收您的身份证资料。平台侧的信息范围、处理目的、权限、保存方式和用户权利请参阅 TapTap 官方隐私政策 及使用相关功能时的提示。普通离线 APK 不联网，亦不表示 TapTap 平台在提供账号、实名和时长服务时不处理信息。

五、您主动联系我们时的信息

如果您向我们发送邮件，我们会收到您的发件邮箱、邮件内容，以及您主动提供的截图、存档或故障说明。这些信息仅用于答复您的问题、处理隐私请求、排查游戏故障或解决相关争议。请只发送与问题有关的内容，不需要提供身份证号码、账号密码或验证码。

我们仅在处理上述沟通、争议或依法保存所必要的期限内保留这些信息。我们不会将您的联系信息用于广告营销，也不会出售您的个人信息。

六、您的管理与联系权利

您可以在游戏中查看经营进度，使用备份功能复制自己的存档，通过重置进度、系统的清除应用数据或卸载功能删除本地数据，并通过文件管理工具删除另行保存的备份。游戏没有独立玩家账号，因此没有需要向开发者申请注销的游戏账号。

对于您通过邮件提供的信息，您可以联系我们提出查询、复制、更正或删除请求。我们会尽快核实并答复；若问题较复杂，会说明处理进度和原因。与 TapTap 平台账号或平台数据有关的请求，请通过 TapTap 官方隐私政策列出的渠道处理。
